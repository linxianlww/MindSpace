# MindSpace（NekoBox）项目介绍与功能分析

> 一款**本地优先、隐私至上**的 Android 笔记本应用。所有数据完全存储于设备本地，零网络权限、零服务器、零追踪。

---

## 一、项目概述

### 1.1 项目定位

MindSpace（又名 NekoBox）是一款面向注重隐私与数据主权用户的本地笔记本应用。它的核心理念是"你的数据只属于你"——所有铭记、文件夹、字体、设置全部保存在应用私有目录中，不申请任何网络权限。

### 1.2 核心理念

- **本地优先**：数据 100% 存储于应用私有目录，不读公共存储、不申请多余权限
- **隐私唯一**：无任何联网权限，零追踪、零服务器、零云端同步
- **文件即真相**：数据库仅存储元数据，真实文件以结构化方式落盘，可手动备份、可人工排查

### 1.3 目标平台

- 仅限 Android（arm64-v8a 架构）
- 采用 Material 3 Expressive 设计风格
- 支持 Android 12+ 动态取色（Material You / 壁纸取色）

### 1.4 许可证

GNU AGPL-3.0 开源许可证，完全自由软件。

## 二、核心功能：七类"铭记"

MindSpace 使用"铭记"（Memo）作为信息记录的基本单位。每个铭记可以是以下七种类型之一：

### 2.1 📝 文本铭记

功能最丰富的记录类型，适合笔记、文章、日记等场景。

- **富文本编辑**：支持字体、字号、颜色、粗体/斜体/下划线、对齐方式、列表等完整排版能力
- **自定义字体**：导入系统外字体文件（.ttf / .otf），全局字体管理
- **Markdown 导出**：内容可导出为 Markdown 或 Delta 格式
- **背景色与卡片颜色**：可为每个铭记设置个性化颜色，便于视觉分类

### 2.2 🖼️ 媒体集

图片与视频的混合管理单元，像一个迷你相册。

- **混合网格展示**：图片和视频在同一网格中共存，支持瀑布流布局
- **图片查看器**：双击缩放、平移查看
- **图片裁剪**：自由裁剪图片
- **拖拽排序**：长按拖动调整媒体排列顺序
- **视频管理**：支持视频的导入、播放、缩略图展示
- **缩略图缓存**：自动生成缓存缩略图，浏览流畅不重复解码

### 2.3 🎙️ 音频铭记

适合录音笔记、会议记录、语音备忘等场景。

- **录音**：开始/暂停/继续/停止控制，实时计时显示
- **实时波形**：录音时显示音频波形可视化
- **音频播放**：内置播放器，支持播放进度控制
- **裁剪窗口**：可设置起止时间窗口进行裁剪（不重新编码，无损处理）
- **音频元数据**：自动解析时长、采样率等信息

### 2.4 📄 文件铭记

将外部文档导入笔记本中，实现"资料库"功能。

- **PDF 内置阅读**：应用内直接阅读 PDF 文档，无需跳转外部应用
- **DOCX 文本预览**：解析并显示 Word 文档的纯文本内容，支持选中复制
- **XLSX 表格浏览**：解析 Excel 工作簿，多工作表切换查看
- **其他文件类型**：非常规文档调用系统"打开方式"选择器，由用户选择外部应用打开
- **多文件导入**：支持一次选择多个文件批量导入

### 2.5 🔐 TOTP 验证码

将两步验证码（2FA）存储在本地，类似轻量级密码管理器。

- **扫码导入**：扫描 `otpauth://` 协议的二维码（兼容 Google Authenticator / 1Password）
- **动态密码**：本地生成 6 位 TOTP 动态验证码，自动倒计时刷新
- **双码显示**：同时显示当前验证码和下一个验证码，方便从容输入
- **一键复制**：点击即可复制验证码到剪贴板
- **剩余时间环**：环形进度条直观显示验证码有效剩余时间

### 2.6 ✅ 待办

轻量级的清单/任务管理功能。

- **条目管理**：添加、删除、编辑待办条目
- **勾选切换**：点击复选框标记完成/未完成
- **拖拽排序**：长按拖动手柄调整条目顺序
- **快速添加**：顶部输入框快速输入新条目，回车即可提交
- **列表重命名**：每个待办铭记可以自定义标题

### 2.7 📅 纪念日

记录重要日期，自动倒计时/正计时天数。

- **天数展示**：大字显示"还有 N 天" / "已过 N 天" / "就是今天"
- **目标日期**：显示具体的公历或农历目标日期
- **重复规则**：支持每年重复等周期设置
- **日历类型**：支持公历和农历两种日历模式
- **卡片复制**：一键复制纪念日信息到剪贴板

## 三、文件夹与组织

### 3.1 无限层级嵌套

文件夹可以无限层级嵌套，构建任意深度的信息组织架构。在主界面以面包屑导航显示当前位置，点击任意层级可快速跳转。

### 3.2 文件夹管理

- **创建文件夹**：在主界面或任意文件夹内创建子文件夹
- **拖拽移动**：长按文件夹卡片拖拽到其他文件夹中
- **重命名**：双击文件夹名称即可编辑
- **删除与恢复**：软删除机制，删除后可从回收站恢复

### 3.3 回收站机制

- **软删除**：删除铭记或文件夹仅标记删除状态，不立即清除数据
- **回收站管理**：在存储设置中可查看已删除的项目
- **恢复与彻底删除**：可选择恢复项目，或彻底删除释放存储空间

## 四、桌面小组件

提供 4 种原生 Android 桌面小组件，无需打开应用即可快速访问内容。

| 小组件 | 尺寸 | 功能 |
|---|---|---|
| 快捷操作 | 2×1 | 一键快速新建文本铭记或添加待办条目 |

| 待办列表 | 4×3 | 展示待办条目，支持在桌面直接勾选切换完成状态 |
| 媒体轮播 | 3×2 | 浏览媒体集的图片轮播展示 |

## 五、桌面快捷方式

任何铭记都可以添加到桌面，创建直达该铭记的快捷图标。

- **自定义图标**：可选择相册中的图片作为快捷图标
- **首字符图标**：不选图片时自动使用铭记标题首字符生成彩色背景图标
- **Deep Link 直达**：点击桌面图标直接跳转到对应铭记详情页

## 六、主题与个性化

### 6.1 主题模式

- 浅色 / 深色 / 跟随系统 三种模式切换
- Android 12+ 设备支持壁纸取色（动态取色）

### 6.2 自定义主题色

- **种子色取色器**：通过色轮或直接输入 HEX 颜色值定义主题种子色
- **双种子配色体系**：MD3E 配色调色板，自动生成和谐的浅色/深色方案

### 6.3 字体管理

- 导入自定义字体文件（.ttf / .otf）
- 字体预览
- 字体的删除与管理
- 导入的字体在所有文本铭记中可用

## 七、备份与恢复

### 7.1 一键备份

将全部铭记、文件夹结构与字体打包为 zip 文件，保存到用户选择的位置。

- **系统 SAF 集成**：Android 上使用系统文档创建器选择保存位置，无需存储权限
- **时间戳命名**：备份文件自动附加时间戳

### 7.2 一键恢复

从之前导出的 zip 备份文件中恢复全部数据。

- **覆盖恢复**：解压覆盖回应用私有目录
- **重启提示**：恢复完成后提示用户重启应用使数据完整生效

## 八、私密空间

为敏感内容提供额外保护层，需通过 PIN 码或生物识别解锁访问。

### 8.1 PIN 码保护

- **6 位 PIN 码**：创建应用级 PIN 码（独立于设备锁屏密码）
- **修改 PIN**：需要验证旧 PIN 后方可设置新 PIN
- **立即锁定**：可随时手动锁定私密空间

### 8.2 生物识别解锁

- **指纹 / 面容 / 虹膜**：支持设备可用的生物识别方式
- **需要先设置 PIN**：生物识别作为 PIN 的便捷替代方式，仍需有 PIN 作为后备

### 8.3 截屏保护

- 开启后，在私密空间解锁期间禁止应用被截屏或录屏
- 防止敏感信息通过截屏泄露

### 8.4 自动锁定

- 用户导航离开私密空间文件夹时自动锁定
- 返回私密空间需要重新验证身份

## 十、数据安全与隐私设计

### 10.1 零网络权限

应用不申请任何互联网权限，所有操作均在本地完成。分享时才会临时将文件复制到缓存目录供系统分享面板访问。

### 10.2 私有目录存储

所有数据存储在 Android 应用私有目录中：
- 铭记文件以 UUID 命名，避免冲突和猜测
- 数据库仅保存索引和元数据
- 文件系统中同步保存 `meta.json` 快照

### 10.3 安全写入

所有文件写入采用"先写临时文件再重命名"的原子操作模式，确保写入失败时不会损坏原有数据。

### 10.4 缩略图与缓存

- 媒体文件自动生成缩略图缓存于私有缓存目录
- 视频采用懒加载策略
- 在存储设置中可手动清理缓存

## 十二、总结

MindSpace 是一款功能完备的本地优先笔记本应用，核心价值在于：

1. **隐私绝对可控** —— 零网络、零追踪、数据 100% 在你手中
2. **记录形式丰富** —— 文本、图片、视频、音频、文档、验证码、待办、纪念日，覆盖日常多种记录场景
3. **组织管理灵活** —— 无限层级文件夹、颜色标签、桌面小组件与快捷方式
4. **安全可靠** —— 安全写入、软删除、备份恢复、私密空间多重保护
5. **个性定制** —— 主题色、自定义字体、动态取色
